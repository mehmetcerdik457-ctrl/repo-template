# Güvenlik Politikası

## Güvenlik açığı bildirme

Güvenlik açığı ayrıntılarını public issue, discussion veya pull request içinde paylaşmayın.

Repository için GitHub **Security Advisories / Private Vulnerability Reporting** arayüzü kullanılabiliyorsa bildirimi oradan özel olarak gönderin. Bu arayüz kullanılamıyorsa repository sahibine GitHub üzerinden özel ve doğrulanabilir bir iletişim kanalıyla ulaşın.

## Kurallar

- Parola, API anahtarı, token, private key, keystore veya üretim kimlik bilgilerini commit/issue/PR içine koymayın.
- Güvenlik kontrolünü sırf build geçsin diye zayıflatmayın.
- Güvenlikle ilgili değişikliklerde yeniden üretilebilir test veya CI kanıtı ekleyin.
